# Goodsly store dashboard

A lightweight Vue dashboard for managing an ecommerce catalog. Products and categories can be created, edited, searched, and deleted; catalog data is saved in browser local storage.

## Project structure

- `src/category/` contains the category list and form components.
- `src/product/` contains the product list and form components.
- `src/App.vue` contains the shared dashboard layout and catalog state.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.
